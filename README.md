## Running the Work

### HTML Projects

1. Open the required experiment or assignment folder.
2. Locate the `index.html` file.
3. Open it in a web browser.

### Node.js / Express Projects

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies using:

```bash
npm install
```

4. Run the appropriate application entry-point file.

### Database Assignments

Follow the instructions and SQL scripts provided inside the respective assignment folders.
