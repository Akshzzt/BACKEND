1. Types of Cascading Style Sheets

External CSS

Linked Stylesheet (<link>)

Styled from styles.css linked in the <head>. Best for multi-page consistency, caching, and clean separation of structure and presentation.

<link rel="stylesheet" href="styles.css">

Internal CSS

Embedded Block (<style>)

Styled by CSS rules inside the <style> element in <head>. Applies to this single HTML document without extra HTTP requests.

<style> .internal-card { ... } </style>

Inline CSS

Element Attribute (style="...")

Styled directly on this <article> and its children using the HTML style attribute. Overrides external and internal rules on this element.

<article style="border: 2px solid #fb7185;">

@import & Media Stylesheets: styles.css imports shared theme variables and this banner from imported.css via @import url("imported.css");, while <link rel="stylesheet" href="print.css" media="print"> switches to a clean black-on-white print layout when printing (Ctrl+P).

2. Cascade Order & Specificity Precedence

All five boxes below start with the external .cascade-demo class (sky blue). Watch how later rules, higher specificity, inline styles, and !important override it:

1. External CSS only (.cascade-demo) → Sky Blue
2. Internal CSS wins over External (.cascade-demo.internal-wins) → Amber
3. ID Selector wins over Class (#id-wins) → Purple
4. Inline Style wins over ID & Internal (style="color: #fb7185;") → Rose
5. !important overrides Inline Style (color: var(--imp-accent) !important;) → Emerald
Selector / Style Type Example Specificity Weight

Type / Pseudo-element p, ::before 0-0-1 (1)
Class / Attribute / Pseudo-class .card, [data-css-origin], :hover 0-1-0 (10)
ID Selector #id-wins 1-0-0 (100)
Inline style Attribute style="color: #fb7185;" 1-0-0-0 (1000)
