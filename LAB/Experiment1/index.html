    12. Interactive Disclosure & Modal Dialog

    <details> <summary> <dialog>

    What makes HTML5 different from HTML4? (<details> + <summary>)

    HTML5 introduced semantic layout regions, native audio/video playback, 2D canvas, local storage APIs, richer form input types with built-in validation, and native interactive elements such as <details> and <dialog> without third-party plugins.

    Why are obsolete tags like <font> or <marquee> excluded?

    Presentation and animation belong in CSS, not HTML markup. Using standard HTML5 keeps the document accessible, maintainable, and compliant with the WHATWG Living Standard.

    Native HTML5 <dialog>

    This modal uses the browser’s top layer via dialog.showModal(), supporting Esc to dismiss and backdrop styling.
